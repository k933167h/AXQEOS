# AX QE OS v4.9

AX Quality Engineering Operating System — Agentic E2E Starter Kit.

## Architecture

Golden Dataset → Evaluation Orchestrator → T0 Deterministic → T1 Economical Judge → T2 Strong LLM Judge → T3 Human/SME → Calibration / Regression / Continuous QM.

Agentic E2E Execution Plane: TesterArmy e2e execution adapter, OpenTelemetry, Langfuse, Grafana, Plane and Kiwi TC integration targets.

## Status

Repository initialized. The complete v4.9 Starter Kit source import is pending. Do not treat this README as evidence of a fully deployed or validated system.

## Security

Never commit `.env`, credentials, access tokens, or patient data. Use `.env.example` and secret management for deployments.
